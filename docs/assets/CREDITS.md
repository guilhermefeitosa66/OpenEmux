# Credits for the images on the site

Where the games in the site's images, the README and the promo video come from.

Every game shown is from the project's own fictional demo library
(`tools/demo_library.py`): a parody catalogue of invented games. Their covers
and cartridge labels were authored with AI as SVG code, in the style of each
console's era, and are rendered offline by `tools/demo_library.py`. The
gameplay frames are drawn the same way, by `tools/demo_gameplay.py`, from each
title's own scene. No commercial game's name, artwork or logo appears in that
catalogue, and no real game, commercial or homebrew, is shown running.

The Android game screens use the controller skins the Android app ships
(`pkg/android/openemux/src/main/assets/skins/` in
[openemux-android](https://github.com/guilhermefeitosa66/openemux-android)).

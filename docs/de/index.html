Retro-Gaming,
zuerst für Linux gebaut.

OpenEmux packt die Leistung von RetroArch in eine aufgeräumte, GNOME-native Oberfläche — so stöberst du mit Covern durch deine Sammlung, schnappst dir einen Controller und spielst einfach los. Keine Konfigurationsdateien. Kein endloses Einrichten. Entworfen, gebaut und getestet wird zuerst unter Linux; unter Windows läuft dieselbe App, als Beta.

⬇ Für Linux herunterladen ⬇ Für Windows herunterladen Beta ★ Auf GitHub ansehen

Kostenlos und quelloffen · MIT-Lizenz · AppImage, .deb, .rpm & Flatpak für Linux · Installer & portables ZIP für Windows

Warum OpenEmux

Emulation ohne Hausaufgaben

RetroArch ist eine der leistungsfähigsten Emulationsplattformen, die je gebaut wurden. OpenEmux gibt ihr eine Oberfläche, die dir nicht im Weg steht.

🎨

Ein echtes Spieleregal

Deine Bibliothek, nach Konsolen sortiert, mit vollständigen Covern, die automatisch aus dem libretro-Thumbnail-Archiv synchronisiert werden.

✨

Erster Start ohne Einrichtung

Beim ersten Start richtet OpenEmux seine Konfiguration ein und lädt die Kerne, die deine Konsolen brauchen, in etwa zehn Sekunden herunter. Der Rest kommt im Hintergrund, während du stöberst.

🎮

Steuerung pro Konsole

Belege Tastatur und Controller für jedes System in einem übersichtlichen Bereich. Die Tastenbelegung wird beim Start an RetroArch übergeben.

📺

Shader, die einfach gut aussehen

Wähle pro Konsole einen CRT- oder Scanline-Shader aus einem kuratierten Katalog, und er wird einfach angewendet — ohne Expedition durch Shader-Menüs.

🐧

Linux zuerst

Gebaut mit GTK4 und Adwaita, nach der GNOME HIG, und unter Linux getestet, bevor irgendetwas anderes kommt. Linux ist hier keine Nebensache; Windows kommt mit, als Beta.

🔍

BIOS auf einen Blick

Eine klare Checkliste, welche BIOS-Dateien jede Konsole braucht und welche du schon hast. Schluss mit Starts, die stillschweigend scheitern.

Die Philosophie

Spiel die Spiele, die dir gehören

OpenEmux ist eine Oberfläche für RetroArch, gebaut, um Emulation zugänglich zu machen. Es ist keine Quelle für Spiele — es liefert keine Spiele, keine ROMs, keine BIOS-Dateien und wird das auch nie tun.

  • Nutze nur Inhalte, die dir rechtmäßig gehören. Lies deine eigenen Module und Discs aus, oder nutze Sicherungskopien von Spielen, die du gekauft hast.
  • Für Raubkopien ist das nicht gedacht. Urheberrechtlich geschützte Spiele herunterzuladen, die dir nicht gehören, ist in den meisten Ländern illegal.
  • Emulation bewahrt Geschichte. So viel Kunst, Musik und Design aus der Welt der Spiele steckt in empfindlicher, alternder Hardware. Sie spielbar zu halten ist legitim — und es funktioniert am besten, wenn es die Menschen respektiert, die diese Spiele gemacht haben.

Los geht’s

In unter einer Minute startklar

Hol dir ein Paket für deine Distribution, das universelle AppImage, das Flatpak — oder unter Windows den Installer. Um den Rest kümmert sich OpenEmux beim ersten Start.

Linux

AppImage

Jede Distribution

chmod +x OpenEmux-x86_64.AppImage
./OpenEmux-x86_64.AppImage

Kein FUSE? Stell APPIMAGE_EXTRACT_AND_RUN=1 voran.

.deb

Debian / Ubuntu

sudo apt install ./openemux_*_amd64.deb

Ubuntu 24.04 LTS oder neuer.

.rpm

Fedora

sudo dnf install ./openemux-*.x86_64.rpm

Fedora 40 oder neuer.

Flatpak

In der Sandbox, mit automatischen Updates

flatpak install -y flathub org.libretro.RetroArch
flatpak remote-add --if-not-exists --no-gpg-verify \
  openemux https://guilhermefeitosa66.github.io/openemux-flatpak/repo
flatpak install -y openemux io.github.guilhermefeitosa66.OpenEmux

Updates kommen mit flatpak update. Ein .flatpak-Bundle als einzelne Datei liegt ebenfalls auf der Releases-Seite.

Windows Beta

Beide Versionen bringen GTK 4, die Python-Laufzeitumgebung und RetroArch selbst mit, du musst also nichts dazu installieren. Windows 10 oder 11, 64-Bit. Das ist noch neu — wenn etwas nicht rund läuft, eröffne ein Issue.

Installer

Der übliche Weg

OpenEmux-*-setup.exe

Installiert nur für deinen Benutzer, also ohne Administrator-Abfrage. Die Builds sind noch nicht code-signiert: SmartScreen wird warnen, und mit Weitere Informationen → Trotzdem ausführen kommst du daran vorbei.

Portabel

Nichts wird installiert

OpenEmux-*-windows-x86_64.zip

Entpacke es irgendwohin und starte OpenEmux.exe aus dem Ordner OpenEmux\ darin. Ideal für einen USB-Stick oder einen Rechner, auf dem du keine Software installieren kannst.

Prüfsummen

Prüfe deinen Download

Jedes Release enthält eine Datei SHA256SUMS. Leg sie neben die heruntergeladene Datei und führe aus:

sha256sum -c SHA256SUMS --ignore-missing

OK heißt, die Datei ist genau die, die veröffentlicht wurde. Alles andere heißt, sie ist beschädigt oder manipuliert — führe sie nicht aus.

Unter Windows gibt PowerShell den Hash aus, und du vergleichst ihn mit bloßem Auge mit der passenden Zeile in SHA256SUMS:

Get-FileHash .\OpenEmux-*-setup.exe -Algorithm SHA256

Auf den Schultern von Riesen

Danke an RetroArch, libretro & OpenEmu

OpenEmux ist direkt von OpenEmu inspiriert, dem beliebten macOS-Emulator, der Retro-Gaming mühelos und schön wirken ließ. Da OpenEmu nur für macOS existiert, gibt es OpenEmux, um denselben Feinschliff zuerst zu Linux zu bringen, und jetzt auch zu Windows. Nichts davon wäre möglich ohne die großartige Arbeit der Teams von RetroArch und libretro. ❤️
